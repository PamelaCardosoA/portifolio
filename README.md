# Portfólio - Pamela Cardoso

Portfólio pessoal desenvolvido para apresentar projetos, artigos, experiências e habilidades nas áreas de design, desenvolvimento web e tecnologia.

## ✨ Sobre o Projeto

O objetivo deste portfólio é reunir projetos acadêmicos, estudos, artigos e trabalhos desenvolvidos ao longo da trajetória profissional e universitária, criando uma apresentação visual moderna, organizada e responsiva.

 https://portifolio-seven-xi-79.vercel.app/sobre.html

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Vercel (Deploy)

## 🎨 Funcionalidades

- Interface moderna e responsiva
- Seção de projetos
- Seção de artigos
- Cards interativos
- Efeitos visuais e animações
- Links externos clicáveis
- Organização visual profissional
